# TrustTunnel Android Client

Полноценный Android клиент TrustTunnel VPN с интерфейсом, идентичным Qt десктопному приложению.

## Особенности

- **Идентичный дизайн Qt приложению** с брендом Claude (фиолетовый, оранжевый)
- **QR код импорт конфигов** из Qt приложения
- **Сканирование QR кодов** встроенной камерой (ML Kit)
- **Управление конфигурациями** с сохранением
- **Уведомления** о состоянии подключения
- **Настройки** (Kill Switch, Notifications, Log Level)
- **Статистика трафика** (в разработке)

## Требования

- Android SDK 26+ (минимум Android 8.0)
- Android NDK 28.1.13356709+
- Java 11+
- Gradle 8.5+

## Сборка

### Из командной строки

```bash
cd trusttunnel-android

# Debug версия
./gradlew assembleDebug

# Release версия
./gradlew assembleRelease
```

APK будет находиться в `app/build/outputs/apk/`

### Из Android Studio

1. Откройте `trusttunnel-android/` как проект в Android Studio
2. Дождитесь синхронизации Gradle
3. Нажмите Run → Run 'app' или Build → Build Bundle(s) / APK(s)

## Использование

### Привязка по ссылке из личного кабинета

Поддерживается deeplink `firetunnel://enroll?url=<https-ссылка, закодированная в URL>`,
например `firetunnel://enroll?url=https%3A%2F%2Fhotspot.bothammer.ru%2Fenroll%2F<token>`.

- Откройте ссылку в браузере (нажатием на ссылку или кнопку на странице) — запустится
  FireTunnel и попросит подтвердить привязку.
- Либо: «Конфиги» → «+» → «Подключить по ссылке из кабинета» и вставьте `firetunnel://…`
  или обычную `https://…/enroll/<token>`. Ссылку также можно отсканировать как QR-код.

Клиент отправляет `POST <ссылка>` с `{fingerprint, name}`, где
`fingerprint = sha256(ANDROID_ID + ":firetunnel")`, и сохраняет полученный TOML.
Тот же запрос повторяется при каждом запуске приложения и перед подключением
(не чаще раза в минуту на ссылку):

- `200` — конфиг обновляется;
- `403` / `404` — конфиг удаляется, VPN с этим конфигом отключается, показывается `message`;
- `429`, `5xx`, сетевая ошибка — старый конфиг остаётся рабочим.

Ссылка — секрет: хранится в `EncryptedSharedPreferences` и не пишется в логи.

Кроме того, ссылки перепроверяются в фоне раз в 30 минут (при наличии сети) и при
каждом возврате в приложение. Если доступ отозван, приходит уведомление. У привязанных
конфигов в списке есть отметка «Из кабинета · обновлён …».

Для кнопки в кабинете на Android надёжнее intent-URL (с fallback, если приложение не установлено):

```text
intent://enroll?url=<encoded>#Intent;scheme=firetunnel;package=me.pnsrc.firetunnel;S.browser_fallback_url=<url>;end
```

### Импорт конфигурации

1. На Qt клиенте, нажмите кнопку QR для конфигурации
2. На Android, нажмите "Scan QR"
3. Отсканируйте QR код
4. Конфигурация будет импортирована автоматически

### Статистика и пинг

На вкладке VPN во время подключения показываются время сеанса, объём трафика и
скорость, а также число соединений через VPN и в обход. Трафик считается по UID самого
приложения: весь туннель идёт через его сокеты. Под выбором конфига — пинг (время
TCP-соединения) до первого адреса из `[endpoint].addresses`, раз в 30 секунд.

### DNS

DNS для TUN берётся из конфига: если задан `dns_upstreams` (в `[endpoint]` или
устаревший ключ верхнего уровня), запросы обслуживает ядро через эти серверы, иначе
используется AdGuard DNS.

### Раздельное туннелирование по приложениям

«Правила» → «Приложения». Режимы:

- «Все приложения через VPN» — по умолчанию;
- «Выбранные приложения в обход VPN»;
- «Только выбранные приложения через VPN» — если ничего не выбрано, через VPN идут все.

Изменения применяются при следующем подключении. Сам FireTunnel всегда идёт в обход VPN.

### Подключение к VPN

1. Выберите конфигурацию из выпадающего списка
2. Нажмите "Connect"
3. При первом подключении разрешите использование VPN
4. Статус изменится на "CONNECTED"

## Расширение функциональности

### Добавление поддержки trusttunnel-core

Чтобы интегрировать нативный trusttunnel-core:

1. Свяжите library из `platform/android/lib/`
2. Реализуйте JNI обертки в `VpnService.kt`
3. Скомпилируйте trusttunnel-core для Android NDK

```kotlin
// build.gradle.kts
dependencies {
    implementation project(':lib')  // trusttunnel android library
}
```
